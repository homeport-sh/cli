# Homeport

**The CLI of [homeport.sh](https://homeport.sh)** — a platform that deploys
web apps for you: connect a repository and it builds and runs it, no config
needed.

This package currently reserves the name. The full release will make
`npx homeport` install the platform binary automatically.

- Website: https://homeport.sh
- Source: https://github.com/homeport-sh/cli
