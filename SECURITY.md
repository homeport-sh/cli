# Security

Please report a vulnerability privately to **security@homeport.sh**, or
through GitHub's [private vulnerability reporting](https://github.com/homeport-sh/cli/security/advisories/new).
Don't open a public issue. We answer within two working days.

This repository is the homeport CLI and the build-planning packages it
shares with the hosted platform. The platform itself, and the software that
runs apps on its servers, are not here.
